## 4. Issues / Risks Found

The program can receive invalid input from the user.

To reduce this risk, input validation was included for:

- Room condition values other than `clean` or `dirty`.
- Dust level values other than `low`, `medium` or `high`.
- Person status values other than `yes` or `no`.

The program was tested using different valid inputs to verify
that the appropriate rules were applied.

No major runtime error was found during testing.


## 5. Limitations

observations or user interactions.

It does not use machine learning or a trained AI model.

The recommendations are therefore limited to the rules implemented
in the program.
